# FIREFIGHT: Eastern Front (Godot 4 Android)

Тактическая стратегия в реальном времени (RTS / Real-Time Tactics) в сеттинге Второй мировой войны (Восточный фронт), вдохновленная классической игрой Firefight и Close Combat.

## Особенности игры

- **Главное меню**:
  - **Новая игра**: начинает тактическое сражение с расстановкой армий (РККА против Вермахта).
  - **Продолжить**: загружает сохраненное состояние боя (позиции юнитов, HP, потери, камеру).
- **Тактический бой**:
  - Армия СССР (РККА): стрелки с винтовками Мосина, автоматчики с ППШ-41, пулеметчики с ДП-27, командиры отделений.
  - Армия Германии (Вермахт): стрелки с Kar98k, автоматчики с MP40, расчеты MG42, офицеры.
  - Размещение: советские войска на западе (левый край карты), немецкие войска на востоке (правый край карты).
  - Управление под сенсорные экраны Android:
    - **Тап по юниту** — выбор бойца (зеленый тактический круг).
    - **Выделение рамкой** — выбор группы бойцов.
    - **Тап по земле** — приказ на перемещение строем с радио-подтверждением и целевым маркером.
    - **Тап по врагу** — приказ атаковать конкретную цель.
    - **Перемещение камеры** свайпом по экрану и зум кнопками `+` / `-`.
    - **Кнопка "Все войска"** для быстрого выделения всей роты.
- **Окружение и графика**:
  - 16-битный пиксель-арт стиль.
  - Декорации карты: дубы, сосны, кустарники, бревна, воронки от взрывов, окопы, разрушенные кирпичные стены, укрепрайон с бетонным бункером и полуразрушенным деревенским домом.
  - Реалистичные мягкие тени под объектами и юнитами.
  - Звуковые эффекты стрельбы винтовок, автоматов, пулеметов, попаданий, приказов и победного марша.
- **Система сохранения**:
  - Автосохранение состояния боя в `user://savegame.json` при паузе и выходе в меню.
  - Загрузка боя по кнопке "Продолжить".

## Сборка .apk через GitHub Actions (без нагрузки на ПК)

Проект полностью настроен для автоматической компиляции `.apk` в облаке GitHub Actions:

1. Создайте репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы проекта в ваш репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Firefight Godot 4 Initial Release"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```
3. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
4. Дождитесь завершения workflow **Build Android APK** (занимает ~1-2 минуты).
5. В блоке **Artifacts** нажмите на **`Firefight-Android-APK`** и скачайте готовый файл `Firefight.apk` прямо на телефон!

## Структура проекта

```
├── project.godot                # Конфигурация Godot 4
├── export_presets.cfg           # Настройки экспорта Android APK
├── .github/workflows/
│   └── export_android.yml       # CI/CD автоматическая сборка APK на GitHub
├── scenes/
│   ├── main_menu.tscn           # Главное меню (Новая игра / Продолжить / Выход)
│   ├── battle.tscn              # Тактическая карта боя с декорациями и армиями
│   ├── unit.tscn                # Юнит (СССР / Германия, ИИ, анимации, укрытия)
│   ├── bullet.tscn              # Баллистика, пули и трассеры
│   ├── fx.tscn                  # Эффекты: вспышки выстрелов, кровь, воронки
│   ├── camera.tscn              # Тактическая сенсорная камера с зумом и панорамированием
│   └── hud.tscn                 # Интерфейс боя, мини-карта, статус роты, пауза
├── scripts/
│   ├── game_manager.gd          # Автозагрузка: сохранение/загрузка боя
│   ├── sound_manager.gd         # Автозагрузка: менеджер звуковых эффектов
│   ├── main_menu.gd             # Логика меню
│   ├── battle.gd                # Логика карты и управления
│   ├── unit.gd                  # ИИ и механики солдат
│   ├── camera.gd                # Сенсорное управление камерой
│   └── hud.gd                   # Логика интерфейса
└── assets/
    ├── sprites/                 # Пиксель-арт спрайты солдат СССР и Германии
    ├── terrain/                 # Текстуры земли, дорог, воронок и окопов
    ├── props/                   # Деревья с тенями, стены, бункер, воронки
    ├── effects/                 # Вспышки выстрелов, трассеры, кровь
    └── audio/                   # Звуки выстрелов, попаданий, приказов и победы
```
